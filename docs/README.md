## 2 权威层级

1. **代码事实**：实现与文档冲突时以代码为准，就地补文档（同一次提交）。
2. **`AGENT.md`**：纪律与索引；内容一律不写在这里。
3. **本目录**：工程内容的唯一事实源，一层的口径只写一份，别处引用不复述。
4. **上游 Unity 工程**（`../HumanAnatomyVirtualTraining_2026_v1.1`，只读）：数据契约与交互语义的原始出处。

## 3 写作约定

- 第 3 行起五行头：`读者 / 类型 / 权威 / 状态 / 依赖`（台账与机器索引同样适用）。
- 一份文档只写自己那一层；跨层用「见 `xxx.md` §n」引用，不复制表格。
- 未实现的设计必须显式标注「**待实现**」或指向 `TODO.md` 的 `T-n`，不得写成既成事实。
- 数字（体素数、面板数、tag 数）必须可复算，给出出处或命令。
- 过程稿、审核稿放 `.plans/`，不进本目录；正式文档禁止引用过程稿。

## 4 读法

按任务取**一份**内容文档即可（一个任务 ≤ 3 份文档，不通读）：改渲染读 `architecture.md`；补数据读 `business.md`；动流程读 `.workflow/README.md`。
